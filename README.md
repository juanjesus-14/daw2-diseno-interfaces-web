# Diseño de Interfaces Web — 2.º DAW

Prácticas de **maquetación con HTML y CSS** del módulo de Diseño de Interfaces Web de 2.º de DAW (curso 2026-2027): unidades de medida, modelo de cajas, layouts con `float` y con **Flexbox**.

## Tecnologías

HTML5 · CSS3 (unidades relativas y absolutas, márgenes y rellenos, `float`, Flexbox)
